# Angry Judge: The Short Rant Contest

Entry for [Angry Judge: The Short Rant Contest](https://make.fun/c/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun.

`main.ts` writes one short, funny rant about a small everyday annoyance to `/output/entry.txt` — a self-checkout scale that convicts an innocent milk buyer. The rant is 395 characters, inside the 400-character cap.

## Run

```sh
node main.ts
```

It writes the rant to `/output/entry.txt` (or to the path given as the first argument) and refuses to write anything outside 1–400 characters.
